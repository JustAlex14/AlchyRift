# AlchyRift

A NeoForge mod (Minecraft 26.1.2) built on [AlchyX](https://github.com/JustAlex14/AlchyX): rifts into pocket spaces inside the void. Work in progress.

## Building

AlchyX must sit next to this folder (`../AlchyX`): Gradle builds it together with this project.

```
./gradlew build
```
